## 🔧 Guía de Instalación

### Paso 1 — Descargar y Extraer
Guarda `Kick-Full-API-Bot.zip` (~30 MB) y descomprímelo. **Sin contraseña.**

### Paso 2 — Instalar Node.js
Instala **Node.js 20+** desde el sitio oficial.

### Paso 3 — Configurar API Key
Abre `config.json` y añade tu **API key de Kick** y el **canal de destino**.

### Paso 4 — Ejecutar el Bot
Ejecuta el bot desde la terminal o como administrador.

### Paso 5 — Verificar
Abre tu chat de Kick y verifica que el bot está activo.

### Paso 6 — Personalizar
Añade comandos personalizados en la carpeta `commands/`.
